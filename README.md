# 🐾 Animal Adventure Maze

Welcome to **Animal Adventure Maze!** 🦁🐘🐰

Animal Adventure Maze is a fun, interactive and educational maze game specially designed for children aged **3 to 6 years old**. Children can explore colourful mazes, guide adorable animals through different paths, and help them reach their destinations.

## 🎯 Objectives
- Improve children's problem-solving skills.
- Develop logical thinking and decision-making.
- Improve hand-eye coordination.
- Encourage creativity and exploration.
- Provide an enjoyable learning experience.

## 🐼 Game Features
- Colourful and child-friendly animal themes.
- Simple and easy-to-understand controls.
- Different maze challenges.
- Cute animal characters.
- Fun and interactive gameplay.
- Suitable for preschool children aged 3–6.

## 🐯 Animal Characters
Children can explore mazes featuring different animals, such as:
- 🦁 Lion
- 🐘 Elephant
- 🐰 Rabbit
- 🐵 Monkey
- 🐼 Panda
- 🦒 Giraffe

## 👶 Target Audience
Children aged 3–6 years old, especially preschool learners.

## 💻 Technologies Used
- HTML
- CSS
- JavaScript

## 🚀 Goal of the Game
Help the animals find their way through the maze and reach their destination!

**Let's explore, learn and have fun!** 🌈🐾
